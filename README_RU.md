# 💐 Bouquet

Лёгкий браузерный просмотрщик SQLite, CronosPro, Excel (XLS/XLSX), CSV, TSV и текста. Открывайте файлы, просматривайте таблицы и ищите данные. Работает офлайн, без установки и сборки. Выбранные локальные файлы остаются в браузере.

**[Открыть Bouquet онлайн](https://vladaaar.github.io/Bouquet/)** · **[Скачать RU / EN](https://github.com/Vladaaar/Bouquet/releases)**

Для работы офлайн скачайте `bouquet-X.Y.Z-ru.zip` или `bouquet-X.Y.Z-en.zip`, распакуйте и откройте `index.html`. Выберите один или несколько файлов кнопкой **📂 Открыть** либо перетащите файлы и папки в окно. Если файлов или таблиц несколько, выберите нужную из списка.

- Поиск слов, `"точных фраз"`, `-исключений` и `колонка:значение`.
- Переходы по объявленным связям SQLite кнопкой 🔗.
- Прогрессивное чтение больших SQLite-баз.
- Смена языка, тем и подключение JavaScript-плагинов в настройках.

Хотите создать плагин? Начните с [hello.js](modules/hello.js): загрузите его через **Настройки → Плагины → Подключить плагин .js**, затем откройте **👋 Hello** в настройках. Пример добавляет свой раздел, реагирует на смену языка и возвращает к текущему файлу без сброса просмотра. Файл входит в комплект, но автоматически не подключается.

[Документация: локальный сервер, форматы, API плагинов и релизы](docs/DEVELOPMENT_RU.md)

Bouquet — просмотрщик, без SQL-консоли и редактирования. Excel, CSV и текст пока загружаются в память целиком. Если автоматическое восстановление CronosPro не удалось, диалог принимает KOD-таблицу, а не обычный пароль.
