# 💐 Bouquet

Лёгкий браузерный просмотрщик SQLite, CronosPro, Excel (XLS/XLSX), CSV, TSV и текста. Открывайте файлы, просматривайте таблицы и ищите данные. Работает офлайн, без установки и сборки. Выбранные локальные файлы остаются в браузере.

**[Открыть Bouquet онлайн](https://vladaaar.github.io/Bouquet/)** · **[Скачать](https://github.com/Vladaaar/Bouquet/releases)**

При запуске язык определяется по настройкам системы/браузера: русский или английский, запасной вариант — английский. Изменить его можно в настройках.

Для работы офлайн скачайте `bouquet-X.Y.Z-html.zip`, распакуйте и откройте `index.html`. Выберите один или несколько файлов кнопкой **📂 Открыть** либо перетащите файлы и папки в окно. Если файлов или таблиц несколько, выберите нужную из списка.

**Для телефона:** скачайте `bouquet-X.Y.Z-html-android.html` и откройте этот единственный файл в браузере. Некоторые Android-браузеры при открытии локального HTML не загружают соседние JS/CSS; здесь стили, рабочие плагины и библиотека Excel встроены внутрь и работают офлайн.

- Поиск слов, `"точных фраз"`, `-исключений` и `колонка:значение`.
- Установите десктопную сборку для Windows, macOS или Linux из релизов; локальные файлы остаются на компьютере. [Подробности сборки](docs/DESKTOP.md).
- Разворачивайте таблицу на всю область окна кнопкой в головке; выход — той же кнопкой или Esc.
- Переходы по объявленным связям SQLite кнопкой 🔗.
- Прогрессивное чтение больших SQLite-баз.
- Смена языка, тем и подключение JavaScript-плагинов в настройках.

Хотите создать плагин? Начните с [hello.js](https://github.com/Vladaaar/Bouquet/blob/main/modules/hello.js): загрузите его через **Настройки → Прочие плагины → Подключить плагин .js**, затем откройте **👋 Hello** в настройках. Пример добавляет свой раздел, реагирует на смену языка и возвращает к текущему файлу без сброса просмотра. Пример доступен в репозитории исходников и исключён из всех сборок.

[Горячие клавиши](modules/shortcuts/README.md) · [Документация: локальный сервер, форматы, API плагинов и релизы](docs/DEVELOPMENT_RU.md)

Bouquet — просмотрщик, без SQL-консоли и редактирования. Excel, CSV и текст пока загружаются в память целиком. Если автоматическое восстановление CronosPro не удалось, диалог принимает KOD-таблицу, а не обычный пароль.
